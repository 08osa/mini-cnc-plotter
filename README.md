# Mini CNC Pen Plotter

Small CNC pen plotter built for a course project: 3D-printed rack-and-pinion axes driven by three **28BYJ-48 stepper motors** on an Arduino Uno with a CNC shield, running **GRBL**.

## Workflow
1. Draw or trace a shape in **Inkscape** (`media/inkscape_trace.png`).
2. Generate G-code with **jscut** (`media/jscut_toolpath.png`).
3. Stream the G-code to GRBL with **gSender** (`media/gsender.png`).
